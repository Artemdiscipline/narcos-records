# Что сюда класть

Пока файла нет — на его месте тёмный блок нужных пропорций с надписью NARCOS.
Появится файл с таким именем, подхватится сам, в коде ничего менять не надо.

## photos/ — уже на месте

- `studio-01.jpg` — фон первого экрана, общий план зала, 2000×1250
- `studio-02.jpg` — блок «О студии», микрофон, вертикаль 4:5
- `studio-03…05.jpg` — галерея, квадраты 1000×1000
- `studio-06…11.jpg` — галерея, квадраты 600–786 px. Это кадры из постов
  канала, исходников крупнее в открытом доступе нет. При случае заменить

Исходники были на 3000–6000 px и по 8–18 МБ. Кроп, ресайз и сжатие делает
скрипт: соотношение под слот, затем лёгкий unsharp, чтобы после уменьшения
не мылило. Фон первого экрана сжат сильнее остальных — он всё равно лежит
под тёмной вуалью на 42% прозрачности.

Хотите добавить кадров в галерею — кладите квадраты и дублируйте `figure.gi`
в разделе «Работы». Соотношение задаёт класс `ph-1x1`.

## Уже лежит

- `logo-emblem.png` — настоящая эмблема студии, стоит в шапке и подвале.
  Взята с аватара их канала, фон вырезан по яркости, 263×136 с прозрачностью
- `favicon.png`, `apple-touch-icon.png` — иконки вкладки и ярлыка на телефоне
- `og-cover.jpg` — картинка для превью ссылки в мессенджерах, 1200×630

Вордмарк «NARCOS RECORDS» картинкой не лежит: это живой текст на Unbounded,
поэтому чёткий на любом экране. Стили — класс `.brand-word`.

Если у студии найдётся исходник логотипа в векторе или растр покрупнее —
замените `logo-emblem.png`, ничего в коде править не нужно. Нынешние 263 px
хватает для шапки и подвала, но для крупного размещения маловато.

По фото: JPEG на 80–85 или WebP, шире 1920 px смысла нет. Тёмные кадры с
неоном ложатся на эту тему лучше всего, светлые придётся притемнять.
