# assets/ — что сюда положить

Пока файлов нет, на сайте показываются аккуратные плейсхолдеры с правильными
пропорциями (скрипт прячет битую картинку, остаётся тёмный блок с «NARCOS»).
Как только положите файл с нужным именем — он подхватится сам, править код не нужно.

## Логотип

- `logo-emblem.svg` — хромированная эмблема (трайбл/Y2K). Используется в шапке и как apple-touch-icon.
- `favicon.svg` — фавикон.
- Вордмарк «NARCOS RECORDS» в шапке и подвале — живой текст на шрифте Unbounded
  (класс `.brand-word` в `styles.css`), поэтому всегда чёткий и масштабируемый.

## Обложка для соцсетей

- `og-cover.jpg` — 1200×630. Подставляется в Open Graph и Twitter Card.

## Советы

- JPEG качества 80–85 или WebP; ширина не больше 1920 px.
- Тёмные кадры с неоновой подсветкой смотрятся в этой теме лучше всего.
- Все `<img>` уже с `loading="lazy"` (кроме hero — там `fetchpriority="high"`).
