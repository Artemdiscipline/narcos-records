Вордмарк «NARCOS RECORDS» картинкой не лежит: это живой текст на Unbounded,
поэтому чёткий на любом экране. Стили — класс `.brand-word`.

Если у студии найдётся исходник логотипа в векторе или растр покрупнее —
замените `logo-emblem.png`, ничего в коде править не нужно. Нынешние 263 px
хватает для шапки и подвала, но для крупного размещения маловато.

По фото: JPEG на 80–85 или WebP, шире 1920 px смысла нет. Тёмные кадры с
неоном ложатся на эту тему лучше всего, светлые придётся притемнять.
