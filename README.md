# Narcos Records

Лендинг студии звукозаписи в Тюмени. Одна страница, статика: HTML, CSS, JS.
Никаких сборщиков и зависимостей — открыл файл и правь.

Живая версия: https://artemdiscipline.github.io/narcos-records/

```
index.html   разметка и все тексты
styles.css   стили
script.js    навигация, анимации, счётчики
assets/      логотип, иконки, обложка, фото
```

## Что осталось подставить

В `index.html` ищите слово «Место под» — это заглушки плееров.

**Треки.** В разделе «Работы», блок `.audio-grid`. Под каждой карточкой лежит
закомментированный `<iframe>` — раскомментировать, вставить адрес вида
`music.yandex.ru/iframe/track/ТРЕК/АЛЬБОМ` и удалить `<div class="embed-ph">`
из этой же карточки.

**Клипы.** Там же, `.video-grid`. YouTube — `youtube.com/embed/ID`, ВК —
`vk.com/video_ext.php?...`. Карточки с классом `wide` горизонтальные (16:9),
с `tall` — вертикалка под Reels.

**Фото.** Кладутся в `assets/`, имена файлов перечислены в `assets/README.md`.
Пока файла нет, на его месте тёмная заглушка нужных пропорций — вёрстка не
разъезжается.

**Ссылка на Яндекс.Карты.** В блоке отзывов сейчас стоит поиск по названию.
Лучше заменить на прямой адрес карточки организации (класс `yamap-badge`).

Цены, тексты и контакты правятся прямо в `index.html` — разделы подписаны
комментариями `01 — о студии`, `02 — услуги` и так далее.
